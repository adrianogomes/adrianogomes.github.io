P

PHP Secret Scanner LLM

Mestrado · Unipampa · 2026

Ferramenta de linha de comando, em Python, que identifica possíveis segredos expostos em código PHP, como senhas, tokens, chaves de API e credenciais de banco de dados. Usa uma abordagem híbrida: heurísticas apontam as linhas suspeitas, os valores sensíveis são sanitizados e, opcionalmente, um LLM apoia a classificação dos achados, com registro auditável dos prompts enviados. Gera relatórios em Markdown e HTML. Desenvolvida em disciplina do mestrado em Engenharia de Software, com uso intensivo de IA generativa como objeto de estudo, da arquitetura à documentação.

  • Python
  • LLMs
  • Segurança de software
  • Análise estática
  • IA generativa

F

Fatus

Especialização · UFRGS · 2026

Ferramenta de Automatização de Testes Unitários que usa LLMs para gerar casos de teste. Desenvolvida em Python, a Fatus realiza a extração do código-fonte de aplicações PHP construídas com o framework Yii, envia esse contexto a modelos de linguagem de grande escala (LLMs) por meio de API REST e integra os testes gerados ao Codeception, que os executa. Projeto de conclusão da especialização em Engenharia de Software para Aplicações de Ciência de Dados (UFRGS).

  • Python
  • LLMs
  • Testes unitários
  • Codeception

SACV

Graduação · UFRGS · 2023

Sistema de Agendamento de Clínica Veterinária: aplicação web em que tutores e médicos veterinários agendam consultas e gerenciam cadastros. Inclui cadastro de tutores e animais, consulta de prontuários, envio de e-mails, emissão de relatórios e controle de permissões por perfil de usuário. Desenvolvido em PHP com Yii 2.0 e Bootstrap, como trabalho de conclusão do bacharelado em Ciência da Computação da UFRGS.
